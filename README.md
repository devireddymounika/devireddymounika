#### 📱 [RAISE — Rice AI Stress Evaluator](https://play.google.com/store/apps/details?id=com.iirr.raise&hl=en_IN) &nbsp; [![Google Play](https://img.shields.io/badge/Google_Play-Live_App-16A34A?style=flat-square&logo=googleplay&logoColor=white)](https://play.google.com/store/apps/details?id=com.iirr.raise&hl=en_IN)
> Human-in-the-loop smart agriculture platform built with **ICAR-IIRR** to protect farmer crop yields. Combines a **32-class PyTorch EfficientNetV2** model with quantized **TFLite** offline inference (`<350ms`), **Grad-CAM** explainable heatmaps, 1280-dim visual similarity search, and scientist tele-consultation.  
> `Flutter` `Dart` `PyTorch` `TFLite` `FastAPI` `Spring Boot` `PostgreSQL`
