### 💫 Executive Summary

> *"Turning Ideas into Real Solutions • Code. Create. Make an Impact."*

I am an impact-driven **Senior Software Engineer & Web GIS Architect** with over **5 years** of hands-on expertise building production systems at the intersection of **Geospatial Intelligence (GIS)**, **Edge Computer Vision**, **Enterprise Cloud Microservices**, and **Cross-Platform Mobile Apps**.

Leading mission-critical software initiatives across India's premier national research institutes—**ICAR-Indian Institute of Rice Research (IIRR)** and **ICAR-Central Research Institute for Dryland Agriculture (CRIDA)**:

* 📱 **Published Mobile Edge AI:** Architected **RAISE (Rice AI Stress Evaluator)** from concept to the Google Play Store—pairing a 32-class PyTorch EfficientNetV2 deep learning model with offline on-device quantized TFLite inference (&lt;350ms) and cloud fallback.
* 🗺️ **Nationwide Geospatial Infrastructure:** Engineered scalable Web GIS platforms (**IIRR Geo-Rice** and **Rice Pest Pheno-Forecasting**) utilizing OpenLayers, GeoServer, and PostGIS to query, analyze, and visualize multi-decadal agricultural datasets.
* ⚡ **Full-Stack Microservices:** Designed resilient Java Spring Boot and Python FastAPI microservices, automated batch forecasting pipelines (ARIMA & Neural Networks), and high-performance React frontends.
